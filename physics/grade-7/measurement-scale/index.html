Цена деления, погрешность и показание

Тренажёр учит читать шкалы разных приборов и правильно записывать результат измерения.

  1. Выбери две соседние подписанные отметки.
  2. Найди разность их значений.
  3. Посчитай промежутки между ними.
  4. Найди цену деления: разность ÷ число промежутков.
  5. Найди погрешность: Δ = c / 2.
  6. Определи показание прибора.
  7. Запиши результат: x = (значение ± Δ) единица.

Три этапа

1. Учимся2 задания с подробными подсказками.
2. Тренируемся5 заданий. Подсказка открывается по запросу.
3. Проверяю себя10 заданий. Для освоения навыка нужно 8 самостоятельных решений с первой попытки.
Главное правило: считаем промежутки между рисками, а не количество рисок.
Прогресс
Короткое правило

Цена деления = разность двух соседних подписанных значений ÷ число промежутков.

Абсолютная погрешность: Δ = c / 2.
