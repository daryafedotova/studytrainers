# Тренажёр «Фазовые переходы на графике» — дизайн

## Цель

Создать интерактивный тренажёр по физике для 8 класса, который последовательно формирует три связанных навыка:

1. распознавать фазовый переход по выделенному участку графика температуры;
2. решать задачи по полному графику нагревания/охлаждения;
3. строить график `T(t)` по текстовому описанию процесса.

Тренажёр ориентирован на работу с компьютера, интерактивной панели и телефона.

## Методическая основа

В первой версии используются четыре фазовых перехода:

- плавление;
- кристаллизация;
- кипение;
- конденсация.

Испарение, сублимация и десублимация не входят в тренажёр.

Терминология и типы заданий ориентируются на раздел 8 класса «Тепловые явления» из задачника Е. Г. Московкиной и В. А. Волкова: отдельные блоки по плавлению/кристаллизации и парообразованию/конденсации, задания на цепочки тепловых процессов, анализ графика по участкам и построение графика зависимости температуры от времени.

Тренажёр не копирует задания дословно: используются собственные формулировки и наборы числовых данных.

## Общая структура

Тренажёр состоит из трёх уровней.

### Уровень 1. «Определи участок»

- 10 заданий.
- На экране показан полный график `T(t)`, один горизонтальный участок выделен цветом.
- Ученик составляет «паспорт участка».
- Для перехода на уровень 2 необходимо не менее 8 из 10 заданий, выполненных с первой попытки без подсказки.
- Если критерий не выполнен, предлагается пройти новую десятку заданий первого уровня.

### Уровень 2. «Реши задачу по графику»

- 10 заданий.
- На каждом экране сразу показан полный график и один вопрос.
- Используются разные форматы ответа: нажатие на участок графика, выбор карточки, множественный выбор, ввод числового значения температуры.
- Вопросы на длительность процессов не используются.
- Для перехода к бонусному уровню необходимо не менее 8 из 10 заданий, выполненных с первой попытки без подсказки.

### Бонусный уровень. «Построй график»

- 6 заданий.
- Ученик получает текстовое описание теплового процесса.
- На координатной сетке по вертикали указано `T, °C`, по горизонтали — `t, время`.
- График строится через крупные узлы сетки: ученик последовательно выбирает точки, тренажёр автоматически соединяет их отрезками.
- Если время в условии не задано численно, по горизонтальной оси проверяется только правильная последовательность узлов; длины участков по X не оцениваются.
- Если время задано явно, координата по X может проверяться.
- Первые задания содержат два фазовых перехода; последние — смену направления процесса и до четырёх фазовых переходов.

## Интерфейс

Визуально тренажёр должен быть родственен существующему тренажёру «Работа со шкалой прибора»:

- светлая пастельная тема;
- крупные панели с заметной рамкой;
- прогресс и название этапа сверху;
- кнопка «Правило»;
- крупные элементы управления;
- адаптивная вёрстка.

Графики строятся в SVG, а не как PNG. Это позволяет:

- менять температуры и форму графика программно;
- подсвечивать нужный участок;
- делать участки кликабельными;
- сохранять чёткость на больших экранах;
- использовать ту же модель данных для всех уровней.

На телефоне drag-and-drop не является обязательным способом взаимодействия. Основная механика карточек — «нажал карточку → нажал поле». На компьютере перетаскивание можно поддержать как дополнительный способ.

## Правило

В модальном окне «Правило» кратко фиксируется:

- наклонный участок вверх — температура увеличивается;
- наклонный участок вниз — температура уменьшается;
- горизонтальный участок при фазовом переходе — температура не изменяется;
- плавление: твёрдое → жидкое, внутренняя энергия увеличивается;
- кристаллизация: жидкое → твёрдое, внутренняя энергия уменьшается;
- кипение: жидкое → газообразное, внутренняя энергия увеличивается;
- конденсация: газообразное → жидкое, внутренняя энергия уменьшается;
- во время фазового перехода одновременно присутствуют две фазы.

## Уровень 1: паспорт участка

Ученик заполняет пять категорий карточками и одно числовое поле.

Категории:

1. процесс;
2. направление фазового перехода;
3. агрегатное состояние во время процесса;
4. изменение температуры;
5. изменение внутренней энергии;
6. температура процесса — ввод числа.

### Карточки процесса

- Плавление
- Кристаллизация
- Кипение
- Конденсация

### Карточки перехода

- Твёрдое → жидкое
- Жидкое → твёрдое
- Жидкое → газообразное
- Газообразное → жидкое

### Карточки состояния

- Твёрдое + жидкое
- Жидкость + пар
- Только твёрдое
- Только жидкое
- Только газообразное

### Карточки изменения температуры

- Не изменяется
- Повышается
- Понижается

### Карточки внутренней энергии

- Увеличивается
- Уменьшается

## Банк уровня 1

1. Нагревание: `-20 → 0 → 0 → 40`, выделен участок при `0 °C`. Ответ: плавление.
2. Охлаждение: `30 → 0 → 0 → -20`, выделен участок при `0 °C`. Ответ: кристаллизация.
3. Нагревание: `20 → 100 → 100 → 130`, выделен участок при `100 °C`. Ответ: кипение.
4. Охлаждение: `140 → 100 → 100 → 40`, выделен участок при `100 °C`. Ответ: конденсация.
5. Нагревание: `-10 → 35 → 35 → 70`, ответ: плавление при `35 °C`.
6. Охлаждение: `80 → 35 → 35 → -15`, ответ: кристаллизация при `35 °C`.
7. Нагревание: `25 → 78 → 78 → 110`, ответ: кипение при `78 °C`.
8. Охлаждение: `120 → 78 → 78 → 30`, ответ: конденсация при `78 °C`.
9. Полный график нагревания с горизонталями `20 °C` и `90 °C`; выделена нижняя. Ответ: плавление.
10. Полный график охлаждения с горизонталями `90 °C` и `20 °C`; выделена верхняя. Ответ: конденсация.

## Уровень 2: типы задач

1. «На каком участке происходит плавление?» — нажать участок.
2. «При какой температуре происходит плавление?» — ввести число.
3. «Какой процесс происходит на участке BC?» — выбрать карточку.
4. «В каком агрегатном состоянии находится вещество в точке C?» — выбрать состояние.
5. «На каком участке одновременно существуют жидкость и пар?» — нажать участок.
6. «Как изменяется внутренняя энергия вещества на выделенном участке?» — выбрать один из двух вариантов.
7. «Какой переход происходит на участке?» — выбрать направление перехода.
8. «На каком участке нагревается жидкость без изменения агрегатного состояния?» — нажать наклонный участок.
9. «Какова температура кипения вещества?» — ввести число.
10. «Какие фазовые переходы представлены на графике?» — множественный выбор.

Температуры и часть графиков могут параметризоваться. Допустимые примерные значения:

- температура плавления: `-15, 0, 20, 25, 35, 45, 60 °C`;
- температура кипения: `65, 78, 82, 90, 100, 110, 120 °C`;
- всегда `Tкип > Tпл`.

## Подсказки уровней 1–2

Подсказка не сообщает готовый ответ сразу.

Примеры:

- «Посмотри, идёт график до участка вверх или вниз».
- «Определи, какое агрегатное состояние было до горизонтального участка».
- «Температура фазового перехода считывается по вертикальной оси».
- «Если вещество охлаждается, внутренняя энергия уменьшается».
- «Жидкость + пар существуют во время кипения или конденсации».

После неверной попытки подсветить именно ошибочную категорию, а не все ответы сразу.

## Бонусный уровень: механика построения

На экране:

- текст условия;
- координатная сетка;
- крупные узлы;
- построенный график;
- кнопки «Отменить точку», «Очистить», «Проверить»;
- кнопка «Подсказка».

Точки добавляются только последовательно слева направо, кроме специальных заданий со сменой направления температуры; время всё равно увеличивается, меняется только направление по вертикали.

### Проверяемые свойства

- порядок участков;
- рост/спад температуры;
- наличие горизонтальных участков;
- правильные температуры фазовых переходов;
- правильное количество фазовых переходов;
- при явных временах — правильные X-координаты.

Не оценивается художественная точность построения.

## Банк бонусного уровня

1. Нагревание условного вещества: старт `-20 °C`, плавление `20 °C`, кипение `90 °C`, конечная температура пара `120 °C`.
2. Охлаждение: старт `130 °C`, конденсация `80 °C`, кристаллизация `30 °C`, конечная температура `-10 °C`.
3. Вода: лёд `-15 °C` → плавление `0 °C` → кипение `100 °C` → пар выше `100 °C`.
4. Условное вещество: `Tпл = 45 °C`, `Tкип = 110 °C`, нагревание от `10` до `140 °C`.
5. Нагревание с двумя переходами, затем охлаждение до жидкости: плавление `30 °C`, кипение/конденсация `90 °C`; всего три фазовых перехода.
6. Полный цикл: `Tпл = 20 °C`, `Tкип = 80 °C`; нагрев от твёрдого вещества до газа, затем охлаждение обратно до твёрдого состояния; четыре фазовых перехода.

## Диагностика ошибок бонусного уровня

Сообщения должны указывать направление исправления без показа готового графика:

- «Во время фазового перехода температура не должна изменяться».
- «Проверь температуру первого фазового перехода».
- «Проверь температуру второго фазового перехода».
- «После этой точки вещество охлаждается — температура должна уменьшаться».
- «Проверь порядок фазовых переходов».
- «На графике не хватает одного фазового перехода».

## Прогресс и результаты

Верхняя панель показывает текущий уровень и номер задания.

Итоговый экран показывает не только общий результат, но и отдельные навыки:

- распознавание фазовых переходов;
- агрегатные состояния;
- чтение температуры;
- направление изменения внутренней энергии;
- решение задач по графику;
- построение графика — после бонусного уровня.

## Техническая структура

Планируемый путь тренажёра:

`physics/grade-8/phase-transitions/`

Файлы:

- `index.html` — экраны и семантическая разметка;
- `styles.css` — адаптивное оформление;
- `data.js` — банки заданий и конфигурация графиков;
- `graph.js` — SVG-рендеринг графиков, кликабельных участков и узлов;
- `app.js` — состояние тренажёра, уровни, проверка, подсказки, прогресс;
- `tests.html` — автономные браузерные тесты чистых функций и основных переходов состояний.

Никаких внешних библиотек не требуется.

## Критерии готовности

- Тренажёр открывается без сборки на GitHub Pages.
- Все 10 заданий уровня 1 доступны и проверяются.
- Переход на уровень 2 работает по правилу 8/10 с первой попытки без подсказки.
- Все 10 типов задач уровня 2 работают на компьютере и телефоне.
- Бонусный уровень содержит 6 заданий и поддерживает построение графика через узлы.
- Все графики — SVG и остаются чёткими при масштабировании.
- Активные зоны подходят для касания пальцем.
- Ввод текста сводится к числовым значениям температуры.
- Подсказки не раскрывают ответ сразу.
- Итоговый экран показывает диагностику навыков.
- Тренажёр добавлен в библиотеку в раздел «Физика → 8 класс».
